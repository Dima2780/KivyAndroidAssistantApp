# KivyAndroidAssistantApp
# Assistant App

Простое Kivy-приложение — список задач с сохранением.

## Сборка APK

APK собирается автоматически через GitHub Actions.

1. Запушь изменения в `main`.
2. Открой вкладку **Actions** в репозитории.
3. Дождись зелёной галочки (~30 мин).
4. Скачай APK из блока **Artifacts** внизу страницы сборки.

## Установка на телефон

1. Скачай `.apk`.
2. В настройках Android разреши установку из неизвестных источников.
3. Открой файл → Установить.
